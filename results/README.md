# Saved results index

`principal/e9`, `principal/e10`, and `principal/e11` are the final main-article protocols. Each includes the original fit JSONs, all per-state ranking-metric CSVs, diagnostics and protocol. Model weights are omitted from the source repository and preserved in the companion original-export archives. Root summary CSVs are the exact saved summaries (E10 uses its separately verified summaries). Numeric results were not edited during packaging.

`audits` holds the retained E11 numerical audit/CPU sensitivity records and manuscript-derived summaries. `historical` preserves all numerical CSVs from the supplied repository; it has a separate older XGB-only E9 label. Original files can contain absolute paths from their recorded environment; those paths are provenance rather than instructions to access another user's system.

Scores in principal CSVs are fractions; the article reports percentages and percentage-point differences. Do not combine references across separate E9/E11 runs or count seeds/shuffle realizations as extra products. Smoke/preflight diagnostics explicitly marked as not-study-results must not be used as full-budget endpoints.
