\section*{Code and data availability}
The source code, experiment configurations, graph-control constructions, saved per-state and product-level results, statistical analyses, and figure-generation scripts for the principal E9--E11 experiments are publicly available in the accompanying GitHub repository~\cite{GraphEVRepo}. The repository documents the neural-training seeds, graph-control constructions and seeds, hyperparameter settings, leave-one-product-out evaluation protocol, sensitivity analyses, and the separate provenance of historical supporting experiments. The EV-battery dataset is publicly available from Karlsruhe Institute of Technology under DOI \url{https://doi.org/10.35097/emz24pksshndq468}~\cite{Baucks2026Dataset}.
